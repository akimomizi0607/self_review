# AIと一緒にWebアプリを作ろう — 学生用スタートガイド

このフォルダは、ChatGPT / Codex を使いながら6週間でWebアプリを作る授業用です。

## 1. 授業の目的

この授業では、AIに完成品を作ってもらうことが目的ではありません。
AIを「質問するだけの道具」ではなく、「一緒に考え、一緒に作るパートナー」として使うことを目指します。

最終的に、Python / Flask を使ったWebアプリを完成させます。

## 2. 第1週の最初にすること

1. 学生用ZIPをダウンロードし、ドキュメントなど分かりやすい場所に展開する。
2. ChatGPTで「専門ユニット」プロジェクトを作る。
3. プロジェクトの「ソース／資料」のファイル追加から、次の4ファイルを追加する。
   - `PROJECT_INSTRUCTIONS.md`
   - `THEME_GUIDE.md`
   - `week1/requirements.md`
   - `week1/design.md`
4. 一覧に4ファイルが表示されることを確認する。
5. プロジェクトの指示欄に「授業はソースの PROJECT_INSTRUCTIONS.md に沿って進めてください。」と設定する。
6. 昼食後の2コマ目に、同じプロジェクト内で新しいチャットを開き、「専門ユニットの第1週を始めたいです。一緒に考えてください。」と入力する。

通常のチャットへの添付と、プロジェクトのソースへの追加は別の操作です。授業ではソースへ追加します。`AGENTS.md` はPCの `web_app` フォルダに残しておきます。

### 第1週の3コマ

| コマ | 進め方 |
|---|---|
| 1コマ目（100分） | 授業説明、全体像、開発工程、配布ファイルとプロジェクトの準備 |
| 昼休み | 昼食 |
| 2コマ目（100分） | 壁打ち・画面案の修正・配色選び・設計と発表準備70分、9人の発表20分、見直し・保存10分 |
| 3コマ目（100分） | 先生の合図で環境構築。動作確認・先生の確認後、設計PowerPointと日報を別々に作成・確認・提出して終了 |

環境構築を始めるときは `ENV_SETUP.md` を使います。ChatGPTが読めない場合はそのチャットに添付してください。

### 毎週の始め方と引き継ぎ

6週間同じ「専門ユニット」プロジェクトとPCの作業フォルダを使い、週ごとに新しいチャットを開きます。

- 第2週：第1週の設計PowerPointを添付し、「第2週の授業を始めたいです」と入力。
- 第3〜6週：前週の日報と第1週の設計PowerPointを添付し、「第○週の授業を始めましょう」と入力。

長いプロンプトは不要です。必要なコードは、作業中にAIと確認します。
日報は第1週から作ります。第1週は環境構築と先生の確認後に「今日の日報を作りたいです」と伝えます。第2週以降は動作確認後にGitへ記録し、先生の確認後に同じ言葉で日報を作ります。進行度と理解度は自分で決め、AIと日報をまとめて内容を確認し、提出します。
第6週は発表資料と6週間の最終まとめを提出します。
詳しい設計や引き継ぎメモは必要に応じて保存します。AIが文章を表示しただけではPCに保存済みとは限りません。保存先を確かめましょう。

## 3. 3つのテーマ

### テーマA：クラス掲示板
名前とメッセージを投稿・編集・削除できる掲示板を作ります。

### テーマB：読書・映画レビューアプリ
タイトル・感想・星評価を登録して一覧管理するアプリを作ります。

### テーマC：勉強記録アプリ
科目・勉強時間・メモを記録して振り返れるアプリを作ります。

## 4. 6週間の流れ

| 週 | 内容 |
|---|---|
| 第1週 | 説明・準備／壁打ち・設計・発表／環境構築・教員確認・設計PowerPointと日報を提出 |
| 第2週 | Flask起動・HTML表示／自分の画面／Gitに初めて記録・教員確認・日報 |
| 第3週 | 入力・送信／JSON保存・表示／動作確認・Git・教員確認・日報 |
| 第4週 | 編集／削除／動作確認・Git・教員確認・日報 |
| 第5週 | 自分の機能を選ぶ／小さく作る／動作確認・Git・教員確認・日報 |
| 第6週 | AIと発表資料を作る／チーム内発表／修正・Git・教員確認・AI活用のまとめ |

## 5. 作業フォルダ

自分が選んだテーマだけを使います。

例：テーマBを選んだ場合

```text
web_app/
├── AGENTS.md
├── PROJECT_INSTRUCTIONS.md
├── week1/
├── themeA/
├── themeB/
│   ├── week2/
│   ├── week3/
│   ├── week4/
│   └── week5/
└── themeC/
```

各週は前週の完成コードをコピーして続きから作っても構いませんが、先生の指示に従ってください。

## 6. AIの使い方

よい使い方：

```text
Flaskでフォーム送信を追加したいです。
今のコードを見て、まずどこを変更する必要があるか説明してください。
まだ完成コードは書かないでください。
```

```text
このエラーが出ました。
すぐに答えを出さず、まずエラー文のどこを確認すればよいか教えてください。
```

避けたい使い方：

```text
アプリ全部作って
```

```text
エラー全部直して
```

## 7. 大切なルール

- AIが書いたコードでも、自分で説明できるようにする
- 分からないままコピーしない
- エラー文を消さずに読む
- 変更前と変更後の違いを確認する
- AIの提案が正しいとは限らないので、実行して確認する
- 自分で決めた内容とAIの提案を区別する

## 8. サンプルアプリを起動するとき

授業で作った各週のフォルダに移動して、`RUN_GUIDE.md`を参照してください。


## 第5週は一人ひとり違います

第5週は、テーマごとに決められた同じ機能を作る週ではありません。
第1週にChatGPTと相談して候補を考え、第5週に今の進み具合に合わせて選びます。
`THEME_GUIDE.md` に載っている機能は参考例です。
自分のイメージをChatGPTに話し、候補を比べてから決めてください。

## 第1週の発表資料

AIと相談し、要件定義1枚＋画面イメージ付き基本設計1枚のPowerPointを作ります。
配色や雰囲気も自分で選びます。迷ったらAIに候補を出してもらいましょう。
アプリ画面の見本を見て、配置や操作を修正します。発表では、何を作るかと、自分が選んだこと・直したことを1〜2分で説明します。
詳しい内容はMarkdownの要件定義書・基本設計書に残してください。

## 第1週の提出物は2つ

1. 要件定義1枚＋画面イメージ付き基本設計1枚のPowerPoint。
2. 日報（PowerPointとは別ファイル）。

日報もAIと作ります。要件定義・設計・環境構築で何をしたか、進行度、理解度、分かったこと・不明点、次回最初にすることを書きます。進行度・理解度は自分で決めます。
Python・pip・Git・ChatGPT・Codex・仮想環境・Flaskなどは、準備の完了と動作確認の結果を分けて残します。「インストール済みだが動作未確認」「エラーで中断」などもそのまま書き、まだできていないことを次回につなげます。日報を自分で確認し、2つとも提出してから終了します。
