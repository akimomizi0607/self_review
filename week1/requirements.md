# 要件定義書

## 1. アプリの概要・目的

- アプリ名：自分レビュー
- 目的：一日の出来事や気持ちをスレッドごとに日記のように記録し、星評価とグラフで自分の毎日を振り返る。

## 2. 対象ユーザー

- 対象ユーザー：自分（個人利用）
- 利用シーン：一日の出来事を文章と星で記録する。複数回投稿した日は、日付が変わった後にその日の評価と投稿をまとめて振り返る。気持ちの整理用の投稿は、1時間後に消えるスレッドで扱う。

## 3. 基本機能（第2〜4週）

| 週 | 実装する基本機能 |
|----|------------------|
| 第2週 | Flaskでトップページを表示し、スレッドや投稿を一覧として見せる。PCとスマートフォンで読みやすい画面にする。 |
| 第3週 | 投稿フォームから文章と星評価を登録し、JSONに保存して読み出す。星は星集計ONのスレッドで必須、OFFでは不要。画像は任意。 |
| 第4週 | 投稿の編集・削除を行い、動作を確認してGitに記録する。スレッド内で投稿を扱い、特別設定の範囲を確認する。 |

## 4. 第5週の個人拡張

### 壁打ちメモ

- 誰に使ってほしい？：自分
- 自分が使うなら何ができるとうれしい？：一日の出来事を複数のスレッドに記録し、その日の評価を振り返りたい。気持ちの整理用の記録は時間がたったら消したい。
- どんな画面・機能をイメージしている？：全体評価を大きく表示し、日別平均の折れ線グラフと集計対象の投稿数の棒グラフを見られる画面。PC版とスマートフォン版を用意する。
- 参考にしたいアプリや機能：食べログのような五段階の星評価。日記のように投稿を蓄積する。

### ChatGPTと考えた候補

| 候補 | できること | 難易度・必要な技術 |
|------|------------|----------------------|
| 1 | 1時間後に投稿内容が消えるスレッド | 削除期限の保存と、期限到来時・次回起動時の削除が必要。第4週までの進み具合を見て判断する。 |
| 2 | 画像投稿 | JPG/JPEGまたはPNGを最大4枚、1枚5MB以下で受け付ける。形式・容量を確認し、超過時は理由を表示する。 |
| 3 | 22時のメール通知 | 毎晩（初期設定）または未投稿の夜だけに切り替える。SMTP等の送信設定が未決定。 |

### 第5週に作りたいもの（現時点の案）

- 現時点の第一候補：1時間で消えるスレッド
- この機能を選んだ理由：愚痴や自己批判など、長期間見返さない方がよい記録を一時的に書けるようにしたい。
- 最小版でまずできればよいこと：専用スレッドの投稿を1時間後に削除する。サーバー停止中に期限を過ぎた投稿は、次回起動時に削除する。削除対象は本文・画像・星の記録とし、星集計は必ずOFFにする。

※ 第4週までの進み具合によって、候補や実装範囲を見直す。

## 5. データ項目（何を記録するか）

| 項目名 | 説明 | 例 |
|--------|------|-----|
| スレッドID・名前 | 投稿を分けるスレッド | `thread-1`・`一日の評価` |
| 星集計設定 | そのスレッドの星を日別・全体評価に含めるか | `true` |
| 1時間後削除設定 | 投稿を1時間後に削除するか。ONなら星集計は必ずOFF | `false` |
| 投稿ID・スレッドID | 投稿の識別と所属先 | `post-1`・`thread-1` |
| 投稿日時・日付 | 投稿時刻と集計対象の日 | `2026-09-25T10:15`・`2026-09-25` |
| 文章 | 投稿本文。必須 | `今日は人の手伝いができた。` |
| 星評価 | 1〜5。星集計ONのスレッドで必須、OFFでは不要 | `5` |
| 画像ファイル名 | 任意画像の保存先を参照。最大4枚 | `post-1-01.png` |
| 通知設定 | 22時メールを送るか、未投稿の夜だけにするか | `毎晩` |

## 6. 制約条件

- 使用する技術：Python / Flask / Jinja2 / HTML / CSS / JSON / Git
- 個人拡張で追加する技術（予定）：未定。まず授業で扱う技術で実現できる範囲を検討する。
- その他の制約：
  - 初期スレッド「一日の評価」を必ず用意し、削除できない。
  - 初期スレッドがある場合に限り、星集計OFFまたは1時間後削除ONのスレッドを作成できる。新規スレッドの初期値は星集計ON・1時間後削除OFF。
  - 星集計OFFと1時間後削除ONのスレッド投稿は星評価集計に含めない。スレッド横断で見る情報は星評価の集計とグラフ用投稿数に限り、文章・画像・投稿一覧は各スレッド内で扱う。
  - 1時間後削除ONでは星集計を必ずOFFにし、投稿の文章・画像・星の記録を削除する。
  - 1日に複数の集計対象投稿がある場合、その星の平均を日別平均とする。全体評価は日別平均の平均とし、各日を同じ重さにする。評価対象がない日はグラフ上で0点にせず空欄にする。棒グラフは集計対象の投稿数を示す。
  - 画像は任意で最大4枚、JPG/JPEGまたはPNG、1枚5MB以下。容量・形式超過時は保存せずメッセージを表示する。自動圧縮はしない。
  - 毎晩22時に「一日の総括を投稿しましょう！」というメールを送る設定が初期値。設定で「集計対象の投稿がない夜だけ」に切り替えられる。星集計OFFまたは1時間後削除ONの投稿は、この判定上の投稿に含めない。PCとアプリサーバーが稼働中の間に送信する。
  - メール送信先・SMTP等の設定方法、実装範囲は未決定。
  - アプリとPowerPointは明るい雰囲気にし、プロジェクターでも見やすくする。Meiryoのみを使い、文字は大きさにかかわらずボールドにする。

## 7. 完成の目安（第6週時点でどうなっていたいか）

- Flaskの画面でスレッドを選び、一日の文章と必要な星評価を投稿・閲覧・編集・削除できる。
- 投稿とスレッド設定をJSONで扱い、画像を使う場合はファイルとして保存できる。
- 星集計ONの投稿から日別平均・投稿数を表示し、日ごとを同じ重さで全体評価を表示できる。
- PC・スマートフォンで主要な操作が分かり、授業内で実装した範囲と未実装の希望を説明できる。
- 1時間後削除・画像・メール通知の実装範囲は授業の進み具合を見て決める。
